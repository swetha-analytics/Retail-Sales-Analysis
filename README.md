End-to-end retail sales analysis using SQL and Power BI to generate business insights and recommendations.
# Retail Sales Analysis

## Project Overview

This project analyzes a retail sales dataset to identify business insights related to:

- Sales Performance
- Profitability
- Customer Behavior
- Product Performance
- Regional Analysis
- Monthly Sales Trends

## Tools Used

- SQL (MySQL)
- Power BI
- Excel

## Business Questions Answered

- Which region generated the highest sales?
- Which categories generated the highest profit?
- Which products generated losses?
- Which customers generated the highest revenue?
- Monthly sales trend analysis
- Top performing products
- Top performing sub-categories
